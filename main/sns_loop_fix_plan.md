# SNS 루프 수정 계획

## 작업 범위
- `test/main/js/main.js`의 `initializeSnsSwipe()`만 우선 수정한다.
- 필요할 때만 `test/main/css/main.css`에 최소 보정만 반영한다.
- 다른 섹션 구조나 공통 파일 체계는 이번 작업에서 건드리지 않는다.

## 수정 목표
- `sns_section` 카드 드래그 시 좌우로 자연스럽게 무한 루프되도록 보정한다.
- 카드 복제 후 점프 기준을 실제 반복 폭 기준으로 계산해 루프가 끊기지 않게 한다.
- 기존 클래스 규칙과 카멜 표기 함수 규칙을 유지한다.

## 수정 방식
1. 현재 복제 카드를 앞뒤에 붙이는 구조는 유지한다.
2. 첫 번째 실제 카드와 첫 번째 앞쪽 복제 카드의 위치 차이로 반복 폭을 계산한다.
3. 스크롤 경계에 닿으면 그 반복 폭만큼만 보정 점프한다.
4. 복제 카드가 포커스 대상이 되지 않도록 최소한의 접근성 보정을 함께 적용한다.

## 기록 원칙
- 이번 수정 내용은 작업 후 `test/skill.md`와 관련 md에 반영한다.

## 작업 결과
- `initializeSnsSwipe()`의 반복 폭 계산을 앞쪽 복제 카드와 실제 카드 위치 차이 기준으로 수정했다.
- 드래그 중 경계를 넘으면 실제 반복 폭만큼만 보정 점프하도록 바꿨다.
- 복제 카드는 포커스와 클릭 대상에서 제외되도록 정리했다.
- 공통 파일 체계나 다른 섹션은 이번 작업에서 수정하지 않았다.
